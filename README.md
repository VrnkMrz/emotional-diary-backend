# Емоційний щоденник військовослужбовця з можливістю розпізнавання емоцій

## Опис проєкту

Це мультиплатформний вебзастосунок, призначений для самоспостереження та самодіагностики психоемоційного стану військовослужбовців.
Додаток поєднує класичний підхід ведення щоденника з сучасними алгоритмами обробки природної мови (NLP) та штучного інтелекту, які автоматично аналізують текстові записи і визначають емоційний стан користувача.

Основна мета проєкту — допомогти військовим підтримувати психологічну стійкість, відстежуючи динаміку власних емоцій у безпечному та конфіденційному середовищі.

## Основний функціонал

* Безпечна авторизація:
  * Вхід за допомогою JWT-токенів (HttpOnly cookies).
  * Двофакторна автентифікація (2FA) через одноразові коди, надіслані на email.

* Ведення щоденника:
  * Створення текстових нотаток.
  * Вибір емоції зі стандартизованої шкали.
  * Автоматичний NLP-аналіз емоцій (модель GPT-4o-mini).
  
* Звіти та аналітика:
  * Місячні звіти з порівнянням оцінок користувача та ШІ.
  * Календар з кольоровими маркерами настрою.
  * Автоматично згенерований текстовий підсумок.

* Профіль користувача:
  * Перегляд особистих даних, дати оновлення облікового запису.
  * Можливість змінювати нікнейм / позивний.

* Конфіденційність та безпека:
  * Шифрування записів за алгоритмом AES-256.
  * Хешування паролів за допомогою bcrypt.
  * Row-level security для записів у БД (користувач має доступ лише до власних нотаток).

## Архітектура

Система побудована за трирівневою архітектурою:

1. Презентаційний рівень — фронтенд на React + Next.js (SSR/CSR, SEO-friendly, Next.js Router).
2. Прикладний рівень — бекенд на Node.js (Express) + Django REST Framework для бізнес-логіки, автентифікації та роботи з NLP-сервісом.
3. Рівень зберігання даних — PostgreSQL з індексацією, партиціюванням та підтримкою політик безпеки.

Окремий NLP-сервіс реалізовано на Python + spaCy, що виконує:

* очищення, токенізацію та лематизацію тексту,
* zero-shot класифікацію емоцій за допомогою моделі GPT-4o-mini.

## Використані технології

* Frontend: React, Next.js, TailwindCSS
* Backend: Node.js (Express), Django REST Framework
* NLP-сервіс: Python, spaCy, GPT-4o-mini
* База даних: PostgreSQL
* Безпека: AES-256, bcrypt, JWT, HTTPS, 2FA
* Інфраструктура: API Gateway (Node.js), розгортання на 3 вузлах (клієнт, вебсервер, сервер БД)

## Чекліст тестування

### Авторизація

*  Вхід з коректними даними (email, пароль, OTP).
*  Вхід з некоректним email.
*  Вхід з неправильним паролем.
*  Триразовий неправильний ввід пароля - блокування на 5 хвилин.
*  Триразовий неправильний OTP-код - блокування на 5 хвилин.
*  Спроба доступу без авторизації - редирект на сторінку входу.

### Щоденник

*  Створення запису з текстом і вибраною емоцією.
*  Спроба зберегти порожній текст - виведення повідомлення про помилку.
*  Спроба зберегти текст коротший за 20 символів - виведення повідомлення про помилку.
*  Перегляд історії записів у списку.
*  Перегляд детальної інформації по запису.
*  Відображення результатів NLP-аналізу.

### Звіти

*  Генерація місячного звіту.
*  Відображення календаря з емоціями.
*  Порівняння оцінки користувача та NLP.

### Профіль

*  Перегляд особистих даних.
*  Зміна нікнейму (з валідацією).
*  Відображення дати оновлення облікового запису.

### Безпека

*  Перевірка збереження JWT у HttpOnly cookie.
*  Шифрування текстових записів у БД (AES-256).
*  Хешування паролів (bcrypt).
*  Доступ до записів лише власнику (row-level security).
